Appointment Booking Form

This is a simple static booking form. On submit, it opens WhatsApp with a ready message (and optionally email).

Before you use this page:
  • • Replace CLINIC_WHATSAPP_NUMBER in the script (example: 919999999999).
  • • Optionally replace CLINIC_EMAIL for email bookings.

This page does not store data. It sends a booking request message to WhatsApp/email.

Want this connected to a database/CRM later? CGP360 can upgrade it to a full system.
